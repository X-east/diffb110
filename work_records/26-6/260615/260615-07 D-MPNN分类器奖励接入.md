# D-MPNN分类器奖励接入

## 动机

原来的 `chembl_classifier` 是 Morgan/RDKit 描述符加三层 MLP。它适合快速过滤，但表达能力有限，且对分子图拓扑的学习主要依赖手工特征。为了后续把“好分子/相对不好分子”的判别器作为更强奖励信号接入 DDPO/DiffGui reward-only 评估，这次新增一条并行的 `chembl_dmpnn` 链路，不替换旧 MLP。

## 参考来源

- 本地 Chemprop 风格参考：`reference project/prop_gen/chemprop/models/mpn.py`
- 本地 Chemprop 模型包装参考：`reference project/prop_gen/chemprop/models/model.py`
- 本地 scaffold split 参考：`reference project/prop_gen/chemprop/data/scaffold.py`

借鉴点：directed bond message passing、按 Bemis-Murcko scaffold 切分数据集、graph encoder 后接 FFN 分类头。

本项目差异：没有依赖外部 `chemprop` 包；当前 `dif` 和 `diffgui` 环境均未安装 chemprop，所以实现了本地轻量版 D-MPNN，避免 reward import 和训练入口被第三方安装状态卡住。

## 改动

新增独立包：

- `chembl_classifier/dmpnn/model.py`：Chemprop-style directed bond message passing，支持 checkpoint 保存/加载。
- `chembl_classifier/dmpnn/data.py`：读取当前 v0.3.1 curated good/bad SMILES，canonicalize，保留 `source/all_labels/weight` 元数据，输出 scaffold split CSV。
- `chembl_classifier/dmpnn/train.py`：从 CSV 训练 D-MPNN，写 checkpoint、`metrics.csv`、`summary.json`。
- `chembl_classifier/dmpnn/predictor.py`：checkpoint-backed predictor，reward 侧按 batch 推理并可缓存 canonical SMILES。
- `chembl_classifier/config_dmpnn_v0_1_scaffold_strongpoly.yaml`：使用当前 v0.3.1 curated scaffold 数据的 D-MPNN 配置。

新增奖励：

- `ddpo/rewards/chembl_dmpnn_reward.py`：新增 `ChemblDMPNNReward`，写入 `chembl_dmpnn_prob` 和 `chembl_dmpnn_reward`，失败分子使用有限 penalty。
- `ddpo/rewards/factory.py`：支持 YAML 中启用 `reward.weights.chembl_dmpnn`。
- `ddpo/runtime/recording/writers/metrics_writer.py`、`ddpo/runtime/recording/run_recorder.py`：加入 epoch summary 和终端展示字段。
- `ddpo/diffgui/runtime/reward_only.py`：reward-only 汇总优先统计 `chembl_dmpnn_reward/prob`。

## 剩余风险

- 当前只完成真实数据整理和训练/奖励代码接入；正式 D-MPNN 大训练尚未启动，默认 checkpoint `chembl_classifier/models/chembl_dmpnn_v0_1_scaffold_strongpoly.pt` 还需要训练生成。
- `chembl_classifier/config_v0_3_1_scaffold_strongpoly.yaml` 中的旧 MLP 样本路径和当前 checkout 可见路径不一致；本次只修正新 D-MPNN 配置，没有改历史 MLP 配置。
- D-MPNN reward 的阈值映射沿用 MLP reward 的 threshold/cap 逻辑，正式使用前应做 MLP vs D-MPNN 的 reward 分布对比和至少一次小规模 DDPO ablation。

## 后续命令

正式训练 D-MPNN：

```bash
conda run -n dif python -m chembl_classifier.dmpnn.train --config chembl_classifier/config_dmpnn_v0_1_scaffold_strongpoly.yaml
```

DDPO 配置中启用示例：

```yaml
reward:
  weights:
    chembl_dmpnn: 1.0
  chembl_dmpnn:
    model_path: chembl_classifier/models/chembl_dmpnn_v0_1_scaffold_strongpoly.pt
    good_threshold: 0.5
    cap_high: 0.8
    cap_low: 0.2
    failure_penalty: -1.0
```
