## 三、训练流程

### 3.1 初始化模型

```python
from models import DiffSBDD
from reward import RewardFunction

model = DiffSBDD(config)
reward_fn = RewardFunction(config)
```

### 3.2 训练循环

```python
for epoch in range(num_epochs):
    # 1. 采样轨迹
    trajectories = model.sample(batch_size=32)
    
    # 2. 计算奖励
    rewards = [reward_fn(traj) for traj in trajectories]
    
    # 3. PPO 更新
    loss = ppo_update(trajectories, rewards)
    
    # 4. 记录指标
    log_metrics(epoch, loss, rewards)
```

### 3.3 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| timesteps | 1000 | 扩散步数 |
| batch_size | 32 | 批大小 |
| learning_rate | 5e-6 | 学习率 |
| ppo_epsilon | 0.0001 | PPO 裁剪范围 |

## 四、奖励函数

### 4.1 化学合理性检查

```python
def is_valid(mol):
    if mol is None:
        return False
    n_atoms = mol.GetNumAtoms()
    return 5 <= n_atoms <= 100
```

### 4.2 对接评分

```python
dg = dock(mol)  # 结合自由能
r_dock = dg / -10.0  # 归一化
```

### 4.3 类药性评分

```python
qed = QED.qed(mol)
sa = SAscore.computeSAscore(mol)
r_drug = 0.5 * qed + 0.5 * (10 - sa) / 9
```

### 4.4 相似性评分

```python
# SMILES → MolFormer → UMAP → KDTree
embedding = molformer.encode(smiles)
z = umap_model.transform(embedding)
distances, _ = kdtree.query(z, k=10)
similarity = 1 / (1 + distances)
r_sim = similarity.mean() if similarity.mean() >= 0.5 else -0.5
```

### 4.5 组合奖励

```python
r_total = 0.4 * r_dock + 0.2 * r_drug + 0.4 * r_sim
```

## 六、常见问题

### Q1: CUDA 内存不足

**A**: 减小 batch_size，启用梯度检查点或混合精度训练

### Q2: 对接失败

**A**: 检查分子构建、添加氢原子、验证对接盒子

### Q3: 相似性评分总是负

**A**: 检查流形数据、MolFormer 编码、相似性阈值

### Q4: 生成分布崩溃

**A**: 减小 PPO epsilon、降低学习率、调整奖励权重
