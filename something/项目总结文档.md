# DiffSBDD-RLPF 项目总结文档

**项目名称**: 基于强化学习的蛋白质特异性分子生成系统  
**目标蛋白**: RE-CmeB (PDB: 8GJJ)  
**核心技术**: DiffSBDD + DDPO (扩散模型 + 强化学习)  
**生成日期**: 2026年3月11日

## 一、项目概述

本项目融合深度学习与强化学习，为特定蛋白质靶点设计高效配体分子。通过以下创新方法实现：

1. **扩散模型基础** (DiffSBDD)：条件扩散模型生成蛋白质结合口袋内的分子
2. **强化学习优化** (DDPO)：PPO 算法优化生成分子的多目标奖励
3. **多维度评估**：综合考虑化学合理性、对接亲和力、类药性和相似性

### 核心创新点

- **SE(3) 等变性**：保持分子的旋转平移不变性
- **多目标优化**：平衡对接、类药性和流形约束
- **实时反馈**：通过对接评分和流形相似性提供即时奖励信号

## 三、扩散模型 (DiffSBDD)

### 3.1 前向过程 (加噪)

$$\mathbf{x}_t = \sqrt{\alpha_t} \mathbf{x}_0 + \sqrt{1 - \alpha_t} \boldsymbol{\epsilon}$$

- $\mathbf{x}_0$：原始分子坐标 $[N, 3]$
- $\alpha_t$：信号保留比例（从1递减到0）
- $T = 1000$：总时间步数

### 3.2 反向过程 (去噪)

$$\mathbf{x}_{t-1} = \frac{1}{\sqrt{\alpha_t}}(\mathbf{x}_t - \sqrt{1-\alpha_t}\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)) + \sigma_t \mathbf{z}$$

**单步对数概率**:
$$\log p(\mathbf{x}_{t-1}|\mathbf{x}_t) = -\frac{1}{2\sigma_t^2}\|\mathbf{x}_{t-1} - \boldsymbol{\mu}_t\|^2 - \log\sigma_t - \frac{D}{2}\log(2\pi)$$

### 3.3 条件生成

通过蛋白质口袋信息条件化生成过程，保持配体-口袋相对位置关系。

## 四、奖励函数系统

### 4.1 完整计算流程

```
生成分子 (3D坐标 x_0, 原子特征 h_0)
    ↓
[1. 化学合理性检查] → 无效? → R_total = -1.0 ✗
    ↓ 有效
[2. 对接评分] → ΔG → R_dock = ΔG / -10.0 ∈ [0, 1.2]
    ↓
[3. 类药性评分] → QED, SA → R_drug = 0.5*QED + 0.5*SA_norm ∈ [0, 1]
    ↓
[4. 相似性评分] → SMILES → MolFormer → UMAP → KDTree → R_sim ∈ [-0.5, 1]
    ↓
[5. 组合奖励] → R_total = 0.4*R_dock + 0.2*R_drug + 0.4*R_sim
```

### 4.2 各奖励分量

#### 4.2.1 化学合理性 (Validity)

检查项：分子非空、原子价态、连通性、大小范围 (5-100 atoms)

#### 4.2.2 对接奖励 (Docking)

$$R_{\text{dock}} = \frac{\text{ΔG}_{\text{binding}}}{-10.0}$$

- ΔG = -10 kcal/mol → R_dock = 1.0
- ΔG = -8 kcal/mol → R_dock = 0.8
- 工具：UniDock (GPU加速)

#### 4.2.3 类药性奖励 (Druglikeness)

$$R_{\text{drug}} = 0.5 \cdot \text{QED} + 0.5 \cdot \text{SA}_{\text{norm}}$$

- QED：定量药物相似性 [0, 1]
- SA：合成可达性，归一化为 (10-SA)/9 ∈ [0, 1]

#### 4.2.4 相似性奖励 (Similarity)

$$R_{\text{sim}} = \begin{cases} 
\bar{s}_k & \text{if } \bar{s}_k \geq 0.5 \\
-0.5 & \text{if } \bar{s}_k < 0.5
\end{cases}$$

工作流：3D分子 → RDKit → SMILES → MolFormer (768维) → UMAP (32维) → KDTree (k=10)

### 4.3 组合奖励

$$R_{\text{total}} = \begin{cases}
-1.0 & \text{if invalid} \\
0.4 \cdot R_{\text{dock}} + 0.2 \cdot R_{\text{drug}} + 0.4 \cdot R_{\text{sim}} & \text{if valid}
\end{cases}$$

## 五、强化学习优化 (DDPO)

### 5.1 PPO 算法框架

#### 5.1.1 重要性采样比率

$$r_t = \frac{\pi_{\text{new}}(\mathbf{x}_t)}{\pi_{\text{old}}(\mathbf{x}_t)} = \exp(\log p_t^{\text{new}} - \log p_t^{\text{old}})$$

#### 5.1.2 优势函数

$$\hat{A}_t = R_t - V_t, \quad V_t = 0.9 \cdot V_{t-1} + 0.1 \cdot R_t$$

标准化：$\hat{A}_t^{\text{norm}} = \frac{\hat{A}_t - \text{mean}(\hat{A})}{\text{std}(\hat{A}) + 1e-8}$

#### 5.1.3 PPO-Clip 损失

$$L_{\text{PPO}} = -\mathbb{E}\left[\min(r_t \hat{A}_t, \text{clip}(r_t, 1-\epsilon, 1+\epsilon)\hat{A}_t)\right]$$

- $\epsilon = 0.0001$：极小裁剪范围（防止扩散模型分布崩溃）

### 5.2 训练循环

```
for epoch in range(num_epochs):
    1. Rollout: 采样轨迹 {x_0, x_1, ..., x_T, log_p_1, ..., log_p_T}
    2. Reward: 计算 R_total
    3. Actor: PPO 更新 (4 个内层 epoch)
    4. Logging: 记录指标
```

### 5.3 关键超参数

| 参数 | 值 | 含义 |
|------|-----|------|
| T | 1000 | 扩散步数 |
| ε | 0.0001 | PPO 裁剪范围 |
| num_epochs | 1000 | 训练轮数 |
| batch_size | 32 | 批大小 |
| learning_rate | 5e-6 | 学习率 |

## 十三、实现细节

### 13.1 数据格式转换

项目中需要处理两种数据格式的转换：

**RLPF 格式** (padded - 填充格式):
- 维度：$\mathbf{X} \in \mathbb{R}^{[B, N, D]}$
- 特点：固定大小，包含 padding mask
- 用途：批处理、GPU 计算

**DiffSBDD 格式** (flat - 扁平格式):
- 维度：$\mathbf{X}_{\text{flat}} \in \mathbb{R}^{[\text{total\_nodes}, D]}$
- 特点：可变大小，无 padding
- 用途：模型推理、灵活处理

**转换流程**:
```
RLPF 格式 (padded)
    ↓
提取有效节点 (根据 batch_mask)
    ↓
DiffSBDD 格式 (flat)
    ↓
模型推理
    ↓
按 batch_mask 填充回 RLPF 格式
```

### 13.2 坐标系统管理

#### 13.2.1 坐标居中

为保持 SE(3) 等变性，所有坐标需要相对于配体中心进行居中：

$$\mathbf{x}_{\text{lig}}' = \mathbf{x}_{\text{lig}} - \bar{\mathbf{x}}_{\text{lig}}$$
$$\mathbf{x}_{\text{pocket}}' = \mathbf{x}_{\text{pocket}} - \bar{\mathbf{x}}_{\text{lig}}$$

其中：
$$\bar{\mathbf{x}}_{\text{lig}} = \frac{1}{N}\sum_{i=1}^{N} \mathbf{x}_{\text{lig},i}$$

**目的**:
- 消除平移自由度
- 保持配体-口袋相对位置
- 提高模型的泛化能力

#### 13.2.2 距离计算

在对接和相似性计算中，需要计算原子间距离：

$$d_{ij} = \|\mathbf{x}_i - \mathbf{x}_j\|_2$$

**优化策略**:
- 使用 PyTorch 的向量化操作
- 利用 GPU 并行计算
- 避免显式循环

### 13.3 批处理策略

#### 13.3.1 动态批处理

由于分子大小不同，采用动态批处理：

```python
# 按分子大小排序
sorted_indices = argsort(num_atoms)

# 分组处理相似大小的分子
for batch in create_dynamic_batches(sorted_indices):
    # 处理该批分子
    process_batch(batch)
```

**优势**:
- 减少 padding 浪费
- 提高 GPU 利用率
- 加快训练速度

#### 13.3.2 梯度累积

对于大分子，使用梯度累积：

```python
for step in range(num_accumulation_steps):
    loss = compute_loss(batch)
    loss.backward()

optimizer.step()
optimizer.zero_grad()
```

## 十四、对接评分详解

### 14.1 UniDock 对接工具

**特性**:
- GPU 加速的分子对接
- 支持刚性和柔性对接
- 快速评分函数

**工作流**:
```
3D 分子坐标 (x_0, h_0)
    ↓
[RDKit 构建分子]
    ├─ 添加氢原子
    ├─ 计算 Gasteiger 电荷
    └─ 生成 3D 坐标
    ↓
[UniDock 对接]
    ├─ 准备受体 (蛋白质)
    ├─ 准备配体 (生成分子)
    ├─ 定义对接盒子
    └─ 运行对接算法
    ↓
[评分]
    ├─ 计算结合自由能 ΔG
    ├─ 提取 RMSD
    └─ 返回对接评分
```

### 14.2 结合自由能计算

UniDock 使用改进的评分函数计算结合自由能：

$$\Delta G = \Delta G_{\text{vdw}} + \Delta G_{\text{hbond}} + \Delta G_{\text{rot}} + \Delta G_{\text{conf}}$$

**各项含义**:
- $\Delta G_{\text{vdw}}$：范德华相互作用
- $\Delta G_{\text{hbond}}$：氢键相互作用
- $\Delta G_{\text{rot}}$：旋转熵损失
- $\Delta G_{\text{conf}}$：构象熵损失

### 14.3 对接评分的奖励映射

原始 ΔG 值范围通常为 [-12, 0] kcal/mol，映射到奖励：

$$R_{\text{dock}} = \frac{\text{ΔG}}{-10.0}$$

**映射示例**:
| ΔG (kcal/mol) | 含义 | R_dock |
|---------------|------|--------|
| -12 | 极强结合 | 1.2 |
| -10 | 强结合 | 1.0 |
| -8 | 中等结合 | 0.8 |
| -5 | 弱结合 | 0.5 |
| 0 | 无结合 | 0.0 |

## 十五、类药性评分详解

### 15.1 QED (Quantitative Estimate of Drug-likeness)

QED 综合评估分子的药物相似性，考虑多个分子描述符：

$$\text{QED} = \prod_{i=1}^{n} \text{desirability}_i$$

**考虑的分子描述符**:

| 描述符 | 范围 | 理想范围 |
|--------|------|--------|
| 分子量 (MW) | 0-900 | 160-480 |
| LogP | -10-10 | -2-5 |
| HBD (氢键供体) | 0-15 | 0-5 |
| HBA (氢键受体) | 0-20 | 2-9 |
| 旋转键 (RotBonds) | 0-30 | 0-8 |
| 芳香环 (AromaticRings) | 0-10 | 1-3 |

**计算方法**:
1. 计算每个描述符的 desirability 值 (0-1)
2. 取几何平均数
3. 结果范围 [0, 1]

### 15.2 SA (Synthetic Accessibility)

SA 评估分子的合成难度，基于已知合成分子的数据库：

$$\text{SA} = \text{complexity} - \text{frequency\_bonus}$$

**特性**:
- 范围：[1, 10]
- 1 = 易合成
- 10 = 难合成

**计算基础**:
- 分子片段频率（从已知合成分子中学习）
- 分子复杂度（原子数、环数等）

**归一化为奖励**:
$$R_{\text{SA}} = \frac{10 - \text{SA}}{9} \in [0, 1]$$

### 15.3 类药性组合

$$R_{\text{drug}} = w_{\text{QED}} \cdot \text{QED} + w_{\text{SA}} \cdot R_{\text{SA}}$$

**权重配置**:
- $w_{\text{QED}} = 0.5$：QED 权重
- $w_{\text{SA}} = 0.5$：SA 权重

**可选配置**:
- $w_{\text{QED}} = 0.6, w_{\text{SA}} = 0.4$：更强调药物相似性
- $w_{\text{QED}} = 0.4, w_{\text{SA}} = 0.6$：更强调合成可达性

## 十六、相似性评分详解

### 16.1 MolFormer 编码

MolFormer 是一个预训练的分子编码器，将 SMILES 转换为高维特征向量：

**架构**:
```
SMILES 字符串
    ↓
[Tokenization] → Token 序列
    ↓
[Embedding] → 嵌入向量
    ↓
[Transformer 编码器] → 上下文表示
    ↓
[CLS Token 提取] → 768 维特征向量
```

**特性**:
- 预训练于 PubChem 数据集（1.1 亿分子）
- 768 维特征空间
- 捕捉分子的语义和结构信息

**计算复杂度**:
- 单个分子：~10-50 ms (GPU)
- 100 万分子：~10-50 小时 (GPU 加速)

### 16.2 UMAP 流形学习

UMAP (Uniform Manifold Approximation and Projection) 将高维特征降维到低维流形：

**参数配置**:
```yaml
n_components: 32          # 输出维度
metric: "cosine"          # 距离度量
n_neighbors: 15           # 邻居数
min_dist: 0.1             # 最小距离
```

**工作原理**:
1. 构建高维空间中的邻域图
2. 在低维空间中优化图的布局
3. 保持局部和全局结构

**优势**:
- 比 t-SNE 更快
- 保持全局结构
- 适合大规模数据

### 16.3 KDTree 最近邻查询

构建 KDTree 索引用于快速最近邻查询：

**复杂度分析**:
- 构建：$O(N \log N)$
- 单次查询：$O(\log N)$
- 批量查询（100 个）：~1-5 ms

**查询过程**:
```
查询点 z_query ∈ R^32
    ↓
[KDTree 遍历]
    ├─ 从根节点开始
    ├─ 递归搜索最近邻
    └─ 剪枝不相关分支
    ↓
返回 k=10 个最近邻
    ├─ 距离 (d_1, ..., d_10)
    └─ 索引 (idx_1, ..., idx_10)
```

### 16.4 加权相似性计算

$$s_i = \frac{1}{1 + d_i}$$

$$w_i = \frac{s_i}{\sum_j s_j}$$

$$\bar{s}_k = \sum_{i=1}^{k} s_i \cdot w_i$$

**含义**:
- $s_i$：第 $i$ 个最近邻的相似性（距离的倒数）
- $w_i$：第 $i$ 个最近邻的权重（相似性归一化）
- $\bar{s}_k$：加权平均相似性

**示例计算**:
```
假设 k=3，距离为 [0.1, 0.3, 0.5]

s_1 = 1/(1+0.1) = 0.909
s_2 = 1/(1+0.3) = 0.769
s_3 = 1/(1+0.5) = 0.667

w_1 = 0.909 / (0.909+0.769+0.667) = 0.408
w_2 = 0.769 / 2.345 = 0.328
w_3 = 0.667 / 2.345 = 0.284

s_bar = 0.909*0.408 + 0.769*0.328 + 0.667*0.284 = 0.806
```

### 16.5 相似性阈值判定

$$R_{\text{sim}} = \begin{cases} 
\bar{s}_k & \text{if } \bar{s}_k \geq \tau \\
-0.5 & \text{if } \bar{s}_k < \tau
\end{cases}$$

**参数**:
- $\tau = 0.5$：相似性阈值
- 在流形内：获得正奖励
- 在流形外：获得负奖励 (-0.5)

**目的**:
- 鼓励生成与已知药物相似的分子
- 防止生成完全陌生的分子

## 十七、PPO 算法详解

### 17.1 策略梯度基础

PPO 是一种策略梯度方法，直接优化策略参数 $\theta$：

$$\nabla_\theta J(\theta) = \mathbb{E}[\nabla_\theta \log \pi_\theta(a|s) \cdot A(s,a)]$$

**含义**:
- 增加高优势动作的概率
- 减少低优势动作的概率

### 17.2 重要性采样

由于新旧策略不同，需要使用重要性采样进行修正：

$$\mathbb{E}_{\pi_{\text{old}}}[f(\pi_{\text{new}})] = \mathbb{E}_{\pi_{\text{old}}}\left[\frac{\pi_{\text{new}}}{\pi_{\text{old}}} f(\pi_{\text{new}})\right]$$

**在 DDPO 中**:
$$r_t = \frac{\pi_{\text{new}}(\mathbf{x}_t)}{\pi_{\text{old}}(\mathbf{x}_t)} = \exp(\log p_t^{\text{new}} - \log p_t^{\text{old}})$$

### 17.3 PPO-Clip 机制

为防止策略变化过大，PPO 使用裁剪机制：

$$L_{\text{PPO}} = -\mathbb{E}\left[\min(r_t \hat{A}_t, \text{clip}(r_t, 1-\epsilon, 1+\epsilon)\hat{A}_t)\right]$$

**工作原理**:
```
if A > 0 (好的动作):
    ├─ 如果 r > 1+ε: 使用 (1+ε)*A (裁剪)
    ├─ 如果 1-ε < r < 1+ε: 使用 r*A (无裁剪)
    └─ 如果 r < 1-ε: 使用 (1-ε)*A (裁剪)

if A < 0 (坏的动作):
    ├─ 如果 r < 1-ε: 使用 (1-ε)*A (裁剪)
    ├─ 如果 1-ε < r < 1+ε: 使用 r*A (无裁剪)
    └─ 如果 r > 1+ε: 使用 (1+ε)*A (裁剪)
```

**为什么 ε 很小 (0.0001)**:
- 扩散模型对策略变化极其敏感
- 大的 ε 会导致生成分布崩溃
- 小的 ε 确保保守更新

### 17.4 优势函数估计

使用 GAE (Generalized Advantage Estimation) 估计优势函数：

$$\hat{A}_t = \sum_{l=0}^{\infty} (\gamma \lambda)^l \delta_{t+l}$$

其中：
$$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$$

**简化版本** (项目中使用):
$$V_t = 0.9 \cdot V_{t-1} + 0.1 \cdot R_t$$
$$\hat{A}_t = R_t - V_t$$

**标准化**:
$$\hat{A}_t^{\text{norm}} = \frac{\hat{A}_t - \text{mean}(\hat{A})}{\text{std}(\hat{A}) + 1e-8}$$

## 十三、实现细节

### 13.1 数据格式转换

项目中需要处理两种数据格式的转换：

**RLPF 格式** (padded - 填充格式):
- 维度：X ∈ R^[B, N, D]
- 特点：固定大小，包含 padding mask
- 用途：批处理、GPU 计算

**DiffSBDD 格式** (flat - 扁平格式):
- 维度：X_flat ∈ R^[total_nodes, D]
- 特点：可变大小，无 padding
- 用途：模型推理、灵活处理

### 13.2 坐标系统管理

为保持 SE(3) 等变性，所有坐标需要相对于配体中心进行居中。

### 13.3 批处理策略

采用动态批处理以减少 padding 浪费，提高 GPU 利用率。

## 十五、类药性评分详解

### 15.1 QED (Quantitative Estimate of Drug-likeness)

QED 综合评估分子的药物相似性，考虑多个分子描述符：

考虑的分子描述符：
- 分子量 (MW)：160-480 Da
- LogP：-2-5
- HBD (氢键供体)：0-5
- HBA (氢键受体)：2-9
- 旋转键 (RotBonds)：0-8
- 芳香环 (AromaticRings)：1-3

### 15.2 SA (Synthetic Accessibility)

SA 评估分子的合成难度，范围 [1, 10]：
- 1 = 易合成
- 10 = 难合成

归一化为奖励：R_SA = (10 - SA) / 9 ∈ [0, 1]
