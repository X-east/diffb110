# 奖励函数与药物流形预处理详解

**最后更新**: 2026年3月11日

## 一、新版奖励函数架构

### 1.1 核心改进

相比之前的版本，新的奖励函数有以下关键改进：

1. **化学合理性优先检查**：使用 RDKit 在计算任何其他奖励之前进行严格的化学检查
2. **分离 QED 和 SA**：将类药性分解为两个独立的评分指标
3. **3D → SMILES 转换**：显式处理 3D 分子到 SMILES 的转换过程
4. **流形约束**：使用预训练的药物流形来约束生成分子的分布

### 1.2 完整计算流程

```
生成分子 (3D坐标 x_0, 原子特征 h_0)
    ↓
[RDKit 化学检查]
    ├─ 构建分子对象
    ├─ 检查价态、连通性、大小
    └─ 无效? → R_total = -1.0 ✗ (跳过后续)
    ↓ 有效
[QED 计算]
    ├─ 分子量、LogP、HBD、HBA、旋转键、芳香环
    └─ R_QED ∈ [0, 1]
    ↓
[SA 计算]
    ├─ 合成可达性评分
    └─ R_SA = (10 - SA) / 9 ∈ [0, 1]
    ↓
[类药性组合]
    └─ R_drug = 0.5 * R_QED + 0.5 * R_SA
    ↓
[对接 (Docking)]
    ├─ 分子与蛋白质对接
    ├─ 计算结合自由能 ΔG
    └─ R_dock = ΔG / -10.0
    ↓
[高维特征相似性]
    ├─ SMILES 转换
    ├─ MolFormer 编码 → [768]
    ├─ UMAP 降维 → [32]
    ├─ KDTree 查询 → k=10 最近邻
    ├─ 计算加权相似性 s_bar
    └─ R_sim = s_bar if s_bar ≥ 0.5 else -0.5
    ↓
[组合奖励]
    └─ R_total = 0.4*R_dock + 0.2*R_drug + 0.4*R_sim
```

## 二、3D 分子到 SMILES 的转换

### 2.1 转换流程详解

```
3D 分子坐标 (x ∈ R^[N,3], h ∈ R^[N,D_h])
    ↓
[RDKit 分子构建]
    ├─ 创建 RDKit EditableMol
    ├─ 添加原子（根据 h 的原子类型）
    ├─ 添加键（根据 3D 距离和化学规则）
    └─ 返回 RDKit mol 对象
    ↓
[SMILES 转换]
    ├─ Chem.MolToSmiles(mol)
    ├─ 规范化 SMILES
    └─ 返回 SMILES 字符串
    ↓
[MolFormer 编码]
    ├─ 输入 SMILES
    ├─ Tokenization
    ├─ Transformer 编码
    └─ 输出 768 维指纹
    ↓
[UMAP 降维]
    ├─ 加载预训练 UMAP 模型
    ├─ 转换 768 维 → 32 维
    └─ 输出流形坐标
    ↓
[KDTree 查询]
    ├─ 加载预构建的 KDTree 索引
    ├─ 查询 k=10 最近邻
    └─ 返回距离和索引
    ↓
[相似性计算]
    ├─ s_i = 1 / (1 + d_i)
    ├─ w_i = s_i / Σs_j
    ├─ s_bar = Σ(s_i * w_i)
    └─ 返回相似性奖励
```

## 三、药物流形预处理

### 3.1 预处理概述

药物流形预处理是相似性奖励计算的基础。目标是从大规模药物数据库中学习药物分子在高维特征空间中的分布特性。

**三阶段流程**:
1. **数据收集**：从公开数据库抓取大规模分子数据
2. **特征提取**：使用 MolFormer 将 SMILES 转换为 768 维高维特征
3. **流形学习**：使用 UMAP 将高维特征降维到 32 维，建立 KDTree 索引

### 3.2 数据收集阶段

**推荐数据源**:
- DrugBank: ~13,000 已批准药物
- ChEMBL: ~200万 生物活性分子
- PubChem: ~1.1亿 全面的化学数据库
- ZINC: ~3.5亿 可购买化合物

**选择策略**:
- 优先使用已批准药物（DrugBank）+ 高活性分子（ChEMBL）
- 建议初始规模：10 万 ~ 100 万分子
- 过滤条件：分子量 100-900 Da，原子数 5-150

### 3.3 MolFormer 指纹提取

使用预训练的 MolFormer 模型将 SMILES 转换为 768 维特征向量。

**特性**:
- 预训练于 PubChem 数据集（1.1 亿分子）
- 捕捉分子的语义和结构信息
- 768 维特征空间具有良好的可分离性

**计算复杂度**:
- 单个分子：~10-50 ms
- 100 万分子：~10-50 小时（GPU 加速）

### 3.4 UMAP 流形学习

使用 UMAP 将 768 维特征降维到 32 维。

**参数配置**:
- 输入维度：768
- 输出维度：32
- 距离度量：cosine
- 邻居数：15
- 最小距离：0.1

**计算复杂度**:
- 100 万分子：~1-2 小时（CPU）

### 3.5 KDTree 索引构建

构建 KDTree 索引用于快速最近邻查询。

**复杂度分析**:
- 构建：O(N log N)
- 单次查询：O(log N)
- 批量查询（100 个）：~1-5 ms

### 3.6 运行时相似性计算

**计算时间分解**:
- MolFormer 编码：~20 ms
- UMAP 转换：~1 ms
- KDTree 查询：~1 ms
- 总计：~22 ms/分子

## 四、关键参数总结

### 4.1 奖励权重

| 组件 | 权重 | 范围 |
|------|------|------|
| 对接 (Docking) | 0.4 | [0, 1.2] |
| 类药性 (Druglikeness) | 0.2 | [0, 1] |
| 相似性 (Similarity) | 0.4 | [-0.5, 1] |

### 4.2 相似性计算参数

| 参数 | 值 | 说明 |
|------|-----|------|
| k (最近邻数) | 10 | KDTree 查询数量 |
| τ (相似性阈值) | 0.5 | 判定是否在流形内 |
| 流形维度 | 32 | UMAP 输出维度 |
| 高维特征维度 | 768 | MolFormer 输出维度 |
