# DiffSBDD-RLPF 项目介绍文档

**项目名称**: 基于强化学习的蛋白质特异性分子生成系统  
**目标蛋白**: RE-CmeB (PDB: 8GJJ)  
**核心技术**: DiffSBDD + DDPO  
**最后更新**: 2026年3月11日

---

## 一、关键变量定义

| 变量 | 符号 | 维度 | 含义 |
|------|------|------|------|
| 配体坐标 | $\mathbf{x}_{\text{lig}}$ | $[N, 3]$ | 配体原子坐标 |
| 配体特征 | $\mathbf{h}_{\text{lig}}$ | $[N, D_h]$ | 配体原子类型编码 |
| 口袋坐标 | $\mathbf{x}_{\text{pocket}}$ | $[M, 3]$ | 口袋残基坐标 |
| 时间步 | $t$ | $[0, T]$ | 扩散过程时间步，$T=1000$ |
| 噪声水平 | $\gamma_t$ | $\mathbb{R}$ | 时间 $t$ 的噪声水平 |
| 信号保留比 | $\alpha_t$ | $[0,1]$ | 原始信号保留比例 |
| 噪声标准差 | $\sigma_t$ | $\mathbb{R}^+$ | 高斯噪声标准差 |
| 对数概率 | $\log p_t$ | $\mathbb{R}$ | 单步去噪的对数概率 |
| 奖励 | $R$ | $\mathbb{R}$ | 分子的总奖励 |
| 优势函数 | $A$ | $\mathbb{R}$ | 奖励 - 基线 |
| 策略比率 | $r_t$ | $\mathbb{R}^+$ | $\pi_{\text{new}} / \pi_{\text{old}}$ |
| 分子指纹 | $\mathbf{f}$ | $[768]$ | MolFormer 高维特征 |
| 流形投影 | $\mathbf{z}$ | $[32]$ | UMAP 降维后的特征 |

## 二、前向扩散过程

### 2.1 核心公式

$$\mathbf{x}_t = \sqrt{\alpha_t} \mathbf{x}_0 + \sqrt{1 - \alpha_t} \boldsymbol{\epsilon}$$

**参数说明**:
- $\mathbf{x}_0$：原始分子坐标
- $\mathbf{x}_t$：时间 $t$ 的噪声分子
- $\alpha_t$：信号保留比例
- $\boldsymbol{\epsilon} \sim \mathcal{N}(0, \mathbf{I})$：标准高斯噪声
- $t \in [0, T]$：时间步

### 2.2 噪声调度 (Variance Preserving)

$$\gamma_t = -\log\frac{\alpha_t}{1 - \alpha_t}$$

**时间特性**:
- $t = 0$：$\gamma_0 = 0$（无噪声，$\alpha_0 \approx 1$）
- $t = T$：$\gamma_T \to \infty$（纯噪声，$\alpha_T \approx 0$）

## 三、反向去噪过程

### 3.1 单步去噪公式

$$\mathbf{x}_{t-1} = \frac{1}{\sqrt{\alpha_t}}(\mathbf{x}_t - \sqrt{1-\alpha_t}\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)) + \sigma_t \mathbf{z}$$

**参数说明**:
- $\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)$：神经网络预测的噪声
- $\sigma_t$：噪声标准差
- $\mathbf{z} \sim \mathcal{N}(0, \mathbf{I})$：采样噪声

### 3.2 单步对数概率

$$\log p(\mathbf{x}_{t-1}|\mathbf{x}_t) = -\frac{1}{2\sigma_t^2}\|\mathbf{x}_{t-1} - \boldsymbol{\mu}_t\|^2 - \log\sigma_t - \frac{D}{2}\log(2\pi)$$

其中：
- $\boldsymbol{\mu}_t = \frac{1}{\sqrt{\alpha_t}}(\mathbf{x}_t - \sqrt{1-\alpha_t}\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t))$：预测均值
- $D = 3N$：坐标总维度
- 仅对有效节点计算

### 3.3 轨迹对数概率

$$\log p(\mathbf{x}_0|\mathbf{x}_T) = \sum_{t=1}^{T} \log p(\mathbf{x}_{t-1}|\mathbf{x}_t)$$

**DDPO 中的使用**：每步单独计算 $\log p_t$，用于 PPO 更新

## 四、奖励函数

### 4.1 计算流程

```
生成分子 → 化学检查 → 对接 → 类药性 → 相似性 → 组合
```

### 4.2 化学合理性检查

$$R_{\text{validity}} = \begin{cases} 0 & \text{if valid} \\ -1.0 & \text{if invalid} \end{cases}$$

**检查条件**:
- $N_{\text{atoms}} > 0$：分子非空
- $\text{valence}(\text{atom}) \leq \text{max\_valence}$：原子价态有效
- $N_{\text{fragments}} = 1$：单连通分量
- $5 \leq N_{\text{atoms}} \leq 100$：大小范围

### 4.3 对接奖励

$$R_{\text{dock}} = \frac{\text{ΔG}_{\text{binding}}}{-10.0}$$

**参数说明**:
- $\text{ΔG}_{\text{binding}}$：结合自由能 (kcal/mol)，范围 $[-12, 0]$
- 归一化因子：$-10.0$ kcal/mol 映射为奖励 $1.0$

**示例**:
- $\text{ΔG} = -10$ → $R_{\text{dock}} = 1.0$
- $\text{ΔG} = -8$ → $R_{\text{dock}} = 0.8$
- $\text{ΔG} = 0$ → $R_{\text{dock}} = 0.0$

### 4.4 类药性奖励

$$R_{\text{drug}} = w_{\text{QED}} \cdot \text{QED}(\text{mol}) + w_{\text{SA}} \cdot \text{SA}_{\text{norm}}(\text{mol})$$

其中：
- $\text{QED}(\text{mol}) \in [0, 1]$：定量药物相似性
- $\text{SA}_{\text{norm}} = \frac{10 - \text{SA}}{9} \in [0, 1]$：归一化合成可达性
- $w_{\text{QED}} = 0.5, w_{\text{SA}} = 0.5$（或 $0.6:0.4$）

### 4.5 高维特征相似性奖励

$$R_{\text{sim}} = \begin{cases} 
\bar{s}_k & \text{if } \bar{s}_k \geq \tau \\
-0.5 & \text{if } \bar{s}_k < \tau
\end{cases}$$

**相似性计算**:
$$\bar{s}_k = \frac{\sum_{i=1}^{k} s_i \cdot w_i}{\sum_{i=1}^{k} w_i}, \quad s_i = \frac{1}{1 + d_i}, \quad w_i = \frac{s_i}{\sum_j s_j}$$

**参数**:
- $d_i$：第 $i$ 个最近邻的流形空间距离
- $\tau = 0.5$：相似性阈值
- $k = 10$：最近邻数量

**工作流**:
$$\text{mol}_{3D} \xrightarrow{\text{build}} \text{mol}_{RDKit} \xrightarrow{\text{SMILES}} s \xrightarrow{\text{MolFormer}} \mathbf{f} \xrightarrow{\text{UMAP}} \mathbf{z} \xrightarrow{\text{KDTree}} (d_1, \ldots, d_k)$$

### 4.6 组合奖励

$$R_{\text{total}} = \begin{cases}
-1.0 & \text{if invalid} \\
w_{\text{dock}} R_{\text{dock}} + w_{\text{drug}} R_{\text{drug}} + w_{\text{sim}} R_{\text{sim}} & \text{if valid}
\end{cases}$$

**权重配置**:
- $w_{\text{dock}} = 0.4$：对接权重
- $w_{\text{drug}} = 0.2$：类药性权重
- $w_{\text{sim}} = 0.4$：相似性权重
- $\sum w = 1.0$

## 五、DDPO 算法

### 5.1 重要性采样比率

$$r_t = \frac{\pi_{\text{new}}(\mathbf{x}_t)}{\pi_{\text{old}}(\mathbf{x}_t)} = \exp(\log p_t^{\text{new}} - \log p_t^{\text{old}})$$

**含义**:
- $r_t > 1$：新策略概率更高
- $r_t < 1$：新策略概率更低
- 用于衡量策略变化幅度

### 5.2 优势函数

$$\hat{A}_t = R_t - V_t$$

$$V_t = 0.9 \cdot V_{t-1} + 0.1 \cdot R_t$$

$$\hat{A}_t^{\text{norm}} = \frac{\hat{A}_t - \text{mean}(\hat{A})}{\text{std}(\hat{A}) + 1e-8}$$

**参数说明**:
- $R_t$：当前奖励
- $V_t$：基线（移动平均）
- 标准化减少方差

### 5.3 PPO-Clip 损失

$$L_{\text{PPO}} = -\mathbb{E}\left[\min(r_t \hat{A}_t, \text{clip}(r_t, 1-\epsilon, 1+\epsilon)\hat{A}_t)\right]$$

**参数说明**:
- $\epsilon = 0.0001$：裁剪范围（极小）
- $\text{clip}(r_t, 1-\epsilon, 1+\epsilon)$：限制策略变化
- 取最小值确保保守更新

**为什么 $\epsilon$ 很小**:
- 扩散模型对策略变化极其敏感
- 小的 $\epsilon$ 防止生成分布崩溃
- 确保训练稳定性

### 5.4 训练循环

```
for epoch in range(num_epochs):
    1. Rollout: 生成分子轨迹
       x_0, x_1, ..., x_T, log_p_1, ..., log_p_T
    
    2. Reward: 计算奖励
       R_total = f(x_0, validity, dock, drug, sim)
    
    3. Actor: PPO 更新
       for inner_epoch in range(num_inner_epochs):
           A = R - V
           loss = -min(r*A, clip(r)*A)
           loss.backward()
           optimizer.step()
    
    4. Logging: 记录指标
```

## 六、药物流形预处理

### 6.1 MolFormer 指纹提取

$$\mathbf{f} = \text{MolFormer}(\text{SMILES}) \in \mathbb{R}^{768}$$

**流程**:
1. SMILES 输入
2. Transformer 编码
3. [CLS] token 输出作为分子表示

### 6.2 流形学习

$$\mathbf{z} = \text{UMAP}(\mathbf{f}) \in \mathbb{R}^{32}$$

**参数**:
- 输入维度：768
- 输出维度：32
- 距离度量：cosine
- 邻居数：15

### 6.3 最近邻查询

$$\text{KDTree}(\{\mathbf{z}_i\}_{i=1}^{N}) \rightarrow (d_1, \ldots, d_k)$$

**复杂度**:
- 构建：$O(N \log N)$
- 查询：$O(\log N)$

## 七、实现细节

### 7.1 数据格式转换

**RLPF 格式** (padded):
$$\mathbf{X} \in \mathbb{R}^{[B, N, D]}$$

**DiffSBDD 格式** (flat):
$$\mathbf{X}_{\text{flat}} \in \mathbb{R}^{[\text{total\_nodes}, D]}$$

**转换**:
```
RLPF → 提取有效节点 → flat
flat → 按 batch_mask 填充 → RLPF
```

### 7.2 坐标居中

$$\mathbf{x}_{\text{lig}}' = \mathbf{x}_{\text{lig}} - \bar{\mathbf{x}}_{\text{lig}}$$
$$\mathbf{x}_{\text{pocket}}' = \mathbf{x}_{\text{pocket}} - \bar{\mathbf{x}}_{\text{lig}}$$

其中 $\bar{\mathbf{x}}_{\text{lig}} = \frac{1}{N}\sum_{i=1}^{N} \mathbf{x}_{\text{lig},i}$

**目的**:
- 保持 SE(3) 等变性
- 保持配体-口袋相对位置

## 九、示意图要点

### 9.1 DDPO 训练流程

```
初始化模型 π_old
    ↓
[Epoch Loop]
    ├─ Rollout: 采样轨迹 {x_0, x_1, ..., x_T, log_p_1, ..., log_p_T}
    ├─ Reward: 计算 R_total (validity → dock → drug → sim)
    ├─ Advantage: 计算 A = R - V
    ├─ PPO Update: 最小化 L_PPO = -min(r*A, clip(r)*A)
    ├─ 更新 π_new
    └─ 记录指标
    ↓
[End]
```

### 9.2 奖励计算流程

```
生成分子 (x_0, h_0)
    ↓
[化学检查] → invalid? → R = -1.0 ✗
    ↓ valid
[对接] → ΔG → R_dock = ΔG / -10
    ↓
[类药性] → QED, SA → R_drug = w_QED*QED + w_SA*SA_norm
    ↓
[相似性] → SMILES → MolFormer → UMAP → KDTree → R_sim
    ↓
[组合] → R_total = w_dock*R_dock + w_drug*R_drug + w_sim*R_sim
```

### 9.3 相似性计算流程

```
3D 分子坐标 (x, h)
    ↓
[build_molecule] → RDKit mol
    ↓
[MolToSmiles] → SMILES string
    ↓
[MolFormer] → f ∈ R^768
    ↓
[UMAP] → z ∈ R^32
    ↓
[KDTree.query] → (d_1, ..., d_10)
    ↓
[相似性] → s_i = 1/(1+d_i)
    ↓
[加权平均] → s_bar = Σ(s_i * w_i)
    ↓
[阈值判定] → R_sim = s_bar if s_bar ≥ τ else -0.5
```

## 十、快速参考

### 10.1 关键公式速查

| 公式 | 用途 |
|------|------|
| $\mathbf{x}_t = \sqrt{\alpha_t}\mathbf{x}_0 + \sqrt{1-\alpha_t}\boldsymbol{\epsilon}$ | 前向扩散 |

```
时间维度: t ∈ [0, T]

  ├─ 3D 坐标: [N, 3]
  ├─ 原子特征: [N, D_h]

  ├─ 有效性: {-1.0, 0}

```
