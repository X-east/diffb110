## 七、执行清理的脚本

创建自动化清理脚本 `cleanup.sh`:

```bash
#!/bin/bash
# DiffB110 项目清理脚本

set -e

echo "开始清理 DiffB110 项目..."

# 1. 创建必要的目录
echo "创建归档目录..."
mkdir -p docs/archive docs/development docs/analysis exp/archive log/archive references docs/archive/unidock

# 2. 删除临时文件
echo "删除临时文件..."
rm -f test_*.py
rm -f "k 4) → 创建 verify_task_N() 汇总函数"
rm -f 未命名.*
rm -f "Pasted image 20260109163201.png"
rm -f .git_commit_message.txt

# 3. 删除过时文档
echo "删除过时文档..."
rm -f BUGFIX_REPORT.md DIAGNOSIS_SUMMARY.md ERROR_ANALYSIS.md
rm -f FINAL_FIX_SUMMARY.md REAL_ROOT_CAUSE.md TRAINING_NO_OUTPUT_DIAGNOSIS.md
rm -f LIGHTNING_*.md
rm -f 8GPU_TRAINING_GUIDE.md MULTI_GPU_CPU_CONFIG.md DDP_8GPU_CONFIG_GUIDE.md
rm -f *_TEST_RESULTS.md
rm -f UNIDOCK_INTEGRATION_*.md UNIDOCK_RL_TRAINING_*.md UNIDOCK_ZERO_SCORE_ANALYSIS.md
rm -f 8GPU_CPU_CONFIGS_COMPARISON.md CPU_ADJUSTMENT_SUMMARY.md CPU_RESOURCE_TUNING_GUIDE.md
rm -f CONFIG_TEST_GUIDE.md FINAL_TEST_GUIDE.md
rm -f CHUNKED_DOCKING_OPTIMIZATION.md CHUNKED_SUBMISSION_SUMMARY.md CORRECT_CHUNK_SIZE_GUIDE.md

# 4. 移动开发文档
echo "整理开发文档..."
mv -f AVAILABLE_SCRIPTS.md DOCKING_*.md FIXED_*.md LOGGING_GUIDE.md \
      OPENBABEL_FIX.md RAY_PARALLEL_*.md SMINA_INSTALLATION.md \
      TRAINING_*.md VERIFIED_TRAINING_CONFIGS.md docs/development/ 2>/dev/null || true

# 5. 移动分析文档
echo "整理分析文档..."
mv -f MOLECULAR_REPRESENTATION_ALTERNATIVES.md \
      MOLFORMER_VS_UNIMOL_ANALYSIS.md \
      REFERENCE_DRUG_SIMILARITY_REWARD.md docs/analysis/ 2>/dev/null || true

# 6. 移动科普文档
echo "整理科普文档..."
mv -f 正文35xdc.md 项目科普文档.md 项目技术报告.md docs/ 2>/dev/null || true

# 7. 重命名中文文档
echo "重命名中文文档..."
mv -f 中文DiffSBDD_PROJECT_MODULE_MAPPING_CN.md docs/DiffSBDD_MODULE_MAPPING_CN.md 2>/dev/null || true
mv -f 中文RLPF_PROJECT_MODULE_MAPPING_CN.md docs/RLPF_MODULE_MAPPING_CN.md 2>/dev/null || true

# 8. 移动参考项目
echo "移动参考项目..."
mv -f RL-Diffusion-main molformer-main Uni-Mol-main Uni-Dock references/ 2>/dev/null || true

# 9. 归档旧实验
echo "归档旧实验..."
mv -f exp/cpu-parallel-test exp/ddp-2gpu-test exp/gpu-rl-test \
      exp/test-* exp/archive/ 2>/dev/null || true

# 10. 清理日志
echo "清理日志..."
rm -f log/*lightning*.log
if ls log/*.log 1> /dev/null 2>&1; then
    tar -czf log/archive/logs_$(date +%Y%m%d).tar.gz log/*.log
    rm -f log/*.log
fi

# 11. 清理生成分子
echo "清理旧生成分子..."
rm -rf generated_molecules/molecule_00*
rm -rf generated_molecules/run_202601*

echo "清理完成！"
echo "请检查 docs/, exp/archive/, log/archive/ 目录"
echo "如果确认无误，可以提交更改到 Git"
```

**使用方法**:

## 九、注意事项

### 9.1 备份建议

在执行清理前，建议：

```bash
# 创建完整备份
tar -czf DiffB110_backup_$(date +%Y%m%d).tar.gz DiffB110/

# 或使用 Git 创建备份分支
git checkout -b backup-before-cleanup
git add -A
git commit -m "backup: before cleanup"
git checkout main
```

### 9.2 团队协作

如果是团队项目：
- 在清理前通知团队成员
- 确认没有人正在使用要删除的文件
- 考虑分阶段清理，先归档后删除

### 9.3 Git 历史

- 删除的文件仍在 Git 历史中
- 如需彻底删除，使用 `git filter-branch` 或 `BFG Repo-Cleaner`
- 但通常不建议修改 Git 历史
