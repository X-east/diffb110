# 260528 每日总结

## 前提

今天集中分析 `7gpu-dock-classifier-v0-1_20260528_000841` 的 25 epoch 训练。问题不是训练完全无效，而是 docking 和 classifier 没有形成一致优化方向，classifier reward 过硬且饱和，导致 PPO 学不到细粒度改进信号。

## 干了什么

- 读取 25 epoch 训练输出，统计 validity、docking、classifier reward 和分子性质。
- 对基础 DiffSBDD filtered SDF 上的 classifier probability 分布做对照。
- 分析 top reward 10%、top docking 10% 和全体有效分子的性质差异。
- 归纳后续 RL 监控指标，避免只看 `reward_mean` 和 `avg_docking`。

## 关键结论

1. 训练有效率、QED、Lipinski 有一定改善，但不是朝“合理且 docking 好”的方向稳定改善。
2. classifier reward 显著饱和：多数有效分子被压到接近 `-1`，信号太稀疏。
3. top docking 分子更大、更疏水、更复杂，往往被 classifier 判差，两个 reward 分量冲突。
4. 原始 docking 均值会被异常 outlier 污染，后续不能只看 `avg_docking`。

## 分析结果

今天的核心发现是 reward teacher 和目标不一致。`top reward 10%` 分子更合理，但 `top docking 10%` 分子 LogP/MW/SA/rings 都更高，而且 classifier reward 低。这说明 raw docking 在奖励复杂疏水结构，classifier 又用过硬映射把大部分样本压成同一个惩罚值，PPO 既没有稠密梯度，也没有明确方向。

对后续的影响很直接：RL 线必须加入 soft classifier reward、受约束 docking、复杂度/芳香/三元环/fragment guard；只看 `reward_mean` 和 `avg_docking` 都会误判。

## 下一步

下一步应重建 classifier 正样本定义，补充 top docking 复杂分子 hard negatives，并把 classifier reward 从硬阈值地板改成更连续的 logit/temperature 或 rank-based signal。docking 侧要加入 ligand efficiency、LogP gate、simplicity gate。
