# 260617 每日简报

## 前提

用户提出 honokiol 双酚羟基位点的对称 R-group 替换问题：两侧 R 化学结构应一致，但 3D 坐标应分别适配口袋。今天重点是从理论、离线审计、后处理、真实 fixed-core inpaint 和失败根因几个层面验证这条路线是否可行。

## 干了什么

- 实现 tensor 层对称侧链约束基础：`SymmetrySpec`、h-copy、action mask、审计。
- 设计双侧侧链软耦合完整方案，明确先做离线审计而不是直接进 PPO。
- 实现 honokiol 双羟基 R 位自动识别与审计。
- 构造双 R replacement smoke，验证同 R 成功、缺失/不同 R 失败。
- 实现生成分子 core mapping，不再依赖目标 SDF atom index 保持参考顺序。
- 跑 DiffSBDD fixed-core inpaint GPU 验证，并分析 raw / postprocess 失败原因。
- 对双 R 约束生成失败做架构层根因分析。

### 失败根因

| 根因 | 现象 |
|---|---|
| latent 软约束打不过 argmax 解码 | 目标 O 仍被解码成 C |
| 固定原子不固定键 | 新原子可错误桥接核心，BFS 抓到整个母核 |
| 无边/拓扑约束 | 新原子可连到非目标核心位置，两侧 R 图不受控 |

## 分析结果

1. 固定核本身已经能保住：fixed-core 坐标、原子类型和核心图都可以保持。
2. 当前 DiffSBDD fixed-core inpaint 不能表达“从 C0/C11 指定锚点生成同构双 R”。
3. 软原子类型约束和距离 nudge 不是参数问题，而是架构上缺少离散边/连接拓扑控制。
4. 主线应转向 R-group enumeration + 双位点构象/对接/审计，或明确的 attachment-aware / shared-graph 生成模型，而不是继续调当前 inpaint 参数。
