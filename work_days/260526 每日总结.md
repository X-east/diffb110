# 260526 每日总结

## 前提

今天的核心问题是：DiffSBDD + DDPO 在 docking / ECFP4 / FCFP4 约束下已经出现明显 reward hacking，模型不是简单“没有学”，而是学会了向高碳、低杂原子、复杂环和疏水结构漂移。当天围绕这个问题做了三件事：复盘 62 epoch 训练、测试 MolSkill 是否能做奖励、搭建并接入 ChEMBL-like 高维分类器奖励。

## 干了什么

- 复盘 `7GPU dock+ecfp4+fcfp4` 62 epoch 训练，确认高碳/低杂原子/复杂环漂移。
- 独立搭建 MolSkill 测试环境，并用 ChEMBL 与异常分子测试 reward 方向。
- 扩充 ChEMBL classifier 负样本，训练 2220D MLP 分类器，并接入 DDPO reward。

## 关键结论

1. 原有 docking 主导的奖励会把模型推向全碳/低极性/复杂环方向，ECFP4/FCFP4 prior 权重不足以拉回药物分布。
2. MolSkill 作为 reward 方向不可靠：它给全碳和全硫结构异常高分，不能作为“药物合理性”护栏。
3. ChEMBL-like classifier 是当天最有价值的新增模块，但它仍只是 reward teacher，不能单独解决生成器缺少键/几何先验的问题。

## 分析结果

这一天把后续路线的根问题定下来了：不能只继续调 docking 权重，因为 reward 本身会鼓励“看起来对接好但化学分布坏”的结构。MolSkill 的失败也说明，外部打分器如果没有针对生成器漏洞校准，会比不用更危险。ChEMBL-like classifier 是必要补丁，但它的作用是识别偏离分布，而不是让 DiffSBDD 学会成键、键长和芳香性。

当天的代码方向是正确的：把 classifier 做成独立模块，再接入 DDPO reward；但科学方向上已经暴露出必须增加 descriptor 监控、hard negatives、几何/成键护栏。
