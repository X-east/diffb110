# 260608 每日简报

## 前提

上周末前的 xhe 训练与 DiffSBDD 强化学习都暴露出两个问题：xhe scratch 收敛慢，RL 线存在高碳、低 TPSA、低杂原子漂移；同时旧 ChEMBL-like MLP 分类器虽然离线分数高，但作为 reward 后没有守住生成分布。今天的重点是判断 xhe 是否继续、重建分类器/guard 的数据基础，并准备动态分类器 reward 的离线评估集。

## 干了什么

- 分析 DiffSBDD-xhe DiffGui scratch 长测到 epoch 134 的趋势。
- 重新评估 DiffSBDD 强化学习下一步，不再直接长跑旧 `docking + classifier` 配置。
- 复盘旧三层 MLP 分类器失败原因，明确问题不是模型容量，而是标签边界、reward 映射和分布护栏错位。
- 构建好/坏分子审阅集，按坏分子原因导出 SDF，供人工查看。
- 训练并评估 ChEMBL classifier v0.2.1 weighted hard-negative 版本。
- 用 8 卡生成 5000 个 DiffSBDD 分子，并用 v0.2/v0.2.1 分类器和 guard 字段打分。

## 结果与数据

### xhe scratch 长测

| 指标 | 结果 |
|---|---:|
| 训练进度 | epoch 16-134，约 209k steps |
| Val Real Bond Acc 均值 | 0.2814 |
| Val Real Bond Acc 最佳 | 0.4611, epoch 131 |
| 后期 Real Bond Acc 均值 | 0.3068 |
| 对照 warm-start Real Bond Acc | 约 0.611 |

结论是 scratch 训练仍在缓慢改善，但距离 warm-start 明显偏远，不建议继续把 scratch 当主路线。

### 分类器与审阅集

| 项目 | 数值 |
|---|---:|
| 审阅集总记录 | 48,052 |
| 唯一 canonical SMILES | 39,659 |
| bad | 39,643 |
| good_candidate | 1,781 |
| good_high_conf | 1,224 |
| `bad_top_docking_exploit` | 14,256 |
| `bad_classifier_false_positive` | 1,183 |

v0.2.1 weighted hard-negative 显著降低了最关键的旧分类器漏判：

| bad reason | v0.1 P>=0.5 | v0.2 P>=0.5 | v0.2.1 P>=0.5 |
|---|---:|---:|---:|
| `bad_classifier_false_positive` | 100.00% | 35.58% | 2.58% |
| `bad_bad_bond_length` | 11.33% | 6.67% | 0.44% |
| `bad_top_docking_exploit` | 4.11% | 1.15% | 0.14% |

但 v0.2.1 也明显更严格，基础 DiffSBDD 生成分子中 `P>=0.5` 从 v0.2 的 18.56% 降到 8.30%，不适合直接作为旧式正向 reward。

### 5000 分子离线评分

| 指标 | 数值 |
|---|---:|
| 生成分片 | 8 GPU，每卡 625 条 |
| 合并 SDF records | 5000 |
| scoring valid | 3157 |
| sanitize failed | 1843 |
| `p_good_v02` median | 0.0031 |
| `p_good_v021` median | 0.0007 |
| guard violation any ratio | 52.77% |

固定 `P>=0.5` 继续不适合当主 reward；`rank_v02` / `dynamic_score_v02` 更适合做动态连续信号。

## 分析结果

1. xhe scratch 不值得继续无条件长训，warm-start 和端到端重建验证优先级更高。
2. 分类器失败不是“三层 MLP 太弱”，而是训练标签没有覆盖 RL OOD 失败模式，且 reward 映射太硬。
3. v0.2.1 更适合做 badness / chemistry guard，不适合直接做正向 ChEMBL-like 奖励。
4. RL 下一步应先做 guard audit、reward v0.2 ablation、dense/rank classifier shaping 和小 KL 对照；trajectory replay 必须后置。
