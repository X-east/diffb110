# 260610 每日简报

## 前提

DiffGui RL 入口已跑通后，需要判断 reward 是否真的推动目标性质。前一天 `docking + classifier` 组合到 epoch 21 没有稳定改善，今天转向纯 docking 趋势测试、环复杂度 reward，以及坏分子分类数据整理。

## 干了什么

- 停止旧 `docking + classifier` DiffGui 训练，启动 pure docking 趋势实验。
- 新增 `RingComplexityReward`，启动 `docking + LE + ring_complexity + chemistry_guard` 的 last3 趋势测试。
- 整理坏分子分类中文对照与 Maestro 查看包，修正过度卤代小芳环、稠合环、三元环、高碳疏水和大环规则。

## 分析结果

1. docking-only 更像工程链路验证，不是有效 reward 方向；单独 docking 没有在短期内推动更好分子。
2. ring complexity reward 方向有信息量，但过粗，可能压低正常芳香环。
3. 分类器 v0.3.1 的关键不是盲目扩充负样本，而是把“真坏模式”从过宽规则里拆出来，避免误杀合理药物骨架。
