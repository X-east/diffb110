# 260529 每日总结

## 前提

今天深度阅读了一批参考项目，目的是回答：DiffB110 继续走 DiffSBDD + DDPO 时，哪些成熟机制最值得借鉴。当天没有以单个实验数据为主，而是建立方法库：几何 guidance、显式 edge/bond、prior-agent 约束、replay/top history、rank-based scoring、active learning、合成性/可行性预判。

## 干了什么

- 阅读 BInD、DiffGui、DiffSMol、DrugDiff 等 3D 生成/扩散项目，整理成键、几何和 guidance 思路。
- 阅读 SMILES-RL、ReLeaSE、REINVENT、SHARP 等 RL 项目，整理 replay、prior-agent、diversity filter 和 off-policy 经验。
- 阅读 QADD、MolGen、PoLiGenX/PILOT 等项目，提炼 classifier、rank scoring、latent/pocket conditioning 的可借鉴点。

## 关键结论

1. BInD 最贴近 DiffB110 的几何痛点：bond distance、two-hop distance、steric clash、interaction guidance 都能作为内部/采样约束参考。
2. DiffGui 是显式 bond/halfedge diffusion 和独立 bond predictor 的关键参考。
3. SMILES-RL、ReLeaSE、REINVENT、SHARP 提供了 RL 线可借的 replay、TopHistory、prior-agent、diversity filter、off-policy 思路。
4. QADD 提供 GIN 替代 ECFP4 MLP 作为更强 reward/classifier 的思路。
5. 这一天的总体判断是：不能继续只堆 docking/classifier reward，需要结构护栏、历史好分子回流、prior 约束和模型内部几何/成键增强。

## 结果与数据

| 参考项目 | 可借鉴点 | 对 DiffB110 的意义 |
|---|---|---|
| BInD | bond distance guidance、two-hop guidance、steric clash guidance、interaction edge | 把几何约束前移到采样过程，减少终局 reward 的稀疏性 |
| DiffGui | halfedge/bond diffusion、bond predictor、bond length loss | 解决 DiffSBDD 无显式键变量的问题 |
| DiffSMol | 最后一步 bond prediction、bond/angle/torsion loss | 给轻量 bond-aware head 提供先例 |
| DrugDiff | predictor guidance | 属性控制可在采样中注入，而不是只在 RL 后验惩罚 |
| SMILES-RL | TopHistory、BinCurrent、RND/diversity filter | 为 GoodMoleculePool / replay training 提供直接参考 |
| ReLeaSE | replay + 动态阈值 | 历史高分分子不应丢弃，可动态提高门槛 |
| REINVENT | Prior-Agent regularization | 防止 RL agent 偏离预训练分布太远 |
| SHARP | SAC/off-policy、合成性/动作可行性模块、delta reward | docking 结果昂贵，应考虑复用和可行性预筛 |
| QADD | GIN QA model、rank-based score、迭代重训练 | 可替换或增强当前 ECFP4/FCFP4 MLP classifier |
| PoLiGenX/PILOT | latent conditioning、离散 atom/bond、property/importance sampling | 中长期底座和采样策略参考 |

## 分析结果

260529 的价值在于把“怎么改”从直觉变成有出处的候选模块。最符合当前六个月课题压力的不是整体换成某个大模型，而是拆成熟模块：BInD 的几何 guidance、DiffGui 的 halfedge/成键、SMILES-RL 的历史 replay、REINVENT 的 prior-agent 约束。

这一天也为后续规则奠定了依据：所有模型内部改动都要有参考程序/论文来源，不凭空自造机制。
