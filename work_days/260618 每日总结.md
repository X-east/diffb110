## 结果与数据

### DiffGui 双 R 路线

| 项目 | 数值 |
|---|---:|
| fixed core atoms | 18 |
| R slots per side | 3 |
| forbidden core-new halfedges | 106 |
| k1 strict success | 20/20 |
| k1 nontrivial pair | 0/20 |
| k2 strict success | 2/20 |
| k2 disconnected R slots | 36 |
| k2_chain strict success | 20/20 |
| k3_chain strict success | 20/20 |

结论：不强制 R-chain 时 slot 大量游离；删除游离 slot 会退化成双甲基；强制 R-chain 虽能成功，但 R 图被预设成双乙基/双丙基，不再是生成式探索。因此 DiffGui hard-constraint 双 R 也不适合作为主线。

## 分析结果

1. 双 R 对称侧链路线在 DiffSBDD 和 DiffGui 上都不适合作为当前主线，应保留为负结果和约束工具，不继续接 RL。
2. DiffGui RL 下一步应集中在压制坏环/复杂环、保留合理芳香骨架、保持 valid/MMD/docking 多目标平衡。
3. RND-EPI 相似候选筛选应按不同指纹拆池，不应再用 `max(ECFP4, ECFP6, FCFP4)` 共阈值。
4. DiffSBDD RL 的主要问题不是没学到，而是 reward shortcut：docking 变好同时高碳、低 TPSA、少杂原子漂移。
