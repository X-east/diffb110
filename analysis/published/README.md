# 正式结果发布区

这里仅放逐项审阅的小型结果汇总和复现配置，按任务建立子目录。

每个任务用一份Markdown报告说明输入来源、代码版本、配置、种子、固定尝试数、统计口径和结论边界；图表与CSV/JSON使用相对链接随报告保存。

原始SDF、全量对接、轨迹、日志、模型权重和运行快照留在本地运行/数据目录，报告记录获取方式与校验值。不要把整个实验输出复制进发布区。

提交前检查暂存清单，并运行`conda run -n dif python scripts/check_git_upload.py`。具体规则见[GitHub上传与版本管理规范](../../docs/GitHub上传与版本管理规范.md)。
