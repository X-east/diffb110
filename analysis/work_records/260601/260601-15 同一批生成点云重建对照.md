# 260601-15 同一批生成点云重建对照

## 一、动机/背景

上一轮已经把 DiffSBDD 的“分子重建/成键”抽成可切换模块。下一步需要回答一个更直接的问题：在同一批 DiffSBDD 生成的 atom cloud 上，OpenBabel 和 EDM distance-rule 到底各自造成什么差异。

关键原则是“只采样一次几何，再换不同 reconstruction backend”。否则如果每种方法都重新采样，随机扩散差异会污染成键算法对比。

## 二、本次新增内容

新增脚本：

| 文件 | 作用 |
|------|------|
| `DiffSBDD/analysis/generated_reconstruction_ablation.py` | 采样一次 DiffSBDD ligand atom cloud，然后用多个 reconstruction backend 重建并对比 |

脚本输出：

| 输出 | 说明 |
|------|------|
| `generated_reconstruction_per_molecule.csv` | 每个样本、每个 method 的 sanitize、碎片、键长、环、元素统计、耗时、SMILES |
| `generated_reconstruction_summary.csv` | method 级均值汇总 |
| `*_sanitized.sdf` | 每个 method sanitize 成功的分子 |
| `*.png` | sanitize、bad bond length、fragment、耗时图 |
| `generated_reconstruction_ablation_report.md` | Markdown 汇总报告 |

## 四、500 分子结果

输出目录：

`analysis/generated_reconstruction_ablation_20260601_n500/`

| method | sanitize | bad bond length | fragments | largest fragment frac | aromatic rings | seconds/mol |
|--------|----------|-----------------|-----------|-----------------------|----------------|-------------|
| openbabel | 0.746 | 0.177330 | 1.288 | 0.953554 | 0.284 | 0.002449 |
| edm | 0.162 | 0.033460 | 3.564 | 0.692213 | 0.010 | 0.001632 |

其他共同分布：

| 指标 | 数值 |
|------|------|
| 平均原子数 | 23.068 |

| 平均杂原子数 | 4.724 |
| 平均卤素数 | 0.872 |

## 五、解释

OpenBabel：

- sanitize 明显更高：0.746；
- 分子整体更连通：平均 fragments 1.288，largest fragment frac 0.954；
- 但 bad bond length rate 更高：0.179；
- 说明它能强行补出更像完整分子的键网络，但会接受一部分几何不自然的键长/环。

EDM distance-rule：

- 更快：0.0017 秒/分子；
- bad bond length rate 更低：0.035；
- 但 sanitize 只有 0.162，平均 fragments 3.564；
- 说明距离规则更保守，少连一些不合理键，但会把分子打碎，也更容易出现 valence/sanitize 问题。

结论：EDM distance-rule 不能作为直接替代 OpenBabel 的改进方案。它适合做对照和局部规则参考，但真正值得做的是 supervised bond predictor 或 bond-aware decoder。

## 六、下一步判断

这组结果支持下一步优先做：

1. 用 CrossDocked true bonds 训练独立 bond predictor；
2. 输入使用生成/真实坐标、atom type、距离、pair feature；
3. 输出 bond type `0/1/2/3/aromatic`；
4. 先作为 reconstruction backend 接入 `DiffSBDD/reconstruction`；
5. 再比较 OpenBabel、EDM、bond predictor 三者在同一批 atom cloud 上的 validity、fragment、bad bond length、aromatic/ring、速度。

这比直接上完整 edge diffusion 风险低，也能立刻回答“只换成键器能救多少质量”。
