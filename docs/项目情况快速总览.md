# DiffB110 项目情况快速总览（Cursor 任务前必读）

> **最后更新**: 2026-05-27

## 1. 项目一句话定位

这是一个**面向 RE-CmeB（8GJJ）靶点的分子生成与 RL 优化项目**：
以 `DiffSBDD` 作为 3D 分子扩散生成底座，用 `DDPO(PPO)` + **高维特征分类器奖励**做强化学习优化。

---

## 2. 项目目标规划（当前版本）

### 2.1 总目标
- 生成对目标蛋白口袋友好且与 ChEMBL 分布一致的候选分子
- 在保证化学有效性的前提下，通过多维度奖励信号提升分子质量
- 建立可复现的多 GPU DDP 实验流程（可记录、可追踪、可冒烟测试）

### 2.2 技术路线（当前已验证主线）
1. `DiffSBDD` 负责条件扩散采样（口袋约束下生成配体）
2. `ddpo/main_diffsbdd_ddp.py` 将 DiffSBDD 包装进 **PyTorch 原生 DDP** 训练环
3. 奖励函数由 `CompositeReward` 加权组合，当前支持 **14 种奖励组件**：
   - **对接类**：`DockingReward`（UniDock 后端）、`LigandEfficiencyReward`
   - **类药性**：`QEDReward`、`SAReward`
   - **ChEMBL 先验**：`ChEMBLPriorReward`（ECFP4/FCFP4 指纹相似度）
   - **高维特征分类器**：`ChemblClassifierReward`（2220 维 MLP，核心新增）
   - **人类偏好**：`MolSkillReward`（MolSkill 模型）
   - **分布匹配**：`LogPDistributionReward`（logP 分布对齐）
   - **多样性**：`DiversityReward`（ECFP4/FCFP4 批级多样性控制）
   - **化学有效性**：`ConnectivityReward`（连接性检查）
   - **归一化**：`ComponentNormalizer`（每分量 EMA z-score）、`RewardNormalizer`（全局 z-score）
4. 训练启动：`bash launch/<config>.sh`（torchrun 多 GPU DDP）
5. 输出写入 `OUT/<run_name>_<日期>_<序号>/`，保存 config、epoch 指标、分子记录、checkpoint

### 2.3 关键基础设施
- **分子描述子监控系统**：`ddpo/utils/molecular_descriptors.py`（LogP/TPSA/HBA/HBD/碳比例/杂原子/芳环/MMD/指纹相似度等 22 个指标）
- **冒烟测试**：`launch/smoke.sh`（1 GPU / 1 epoch / batch=4，全链路 DDP 验证 + 自动清理）
- **ChEMBL 分类器管线**：`chembl_classifier/`（数据提取 → 训练 → 评估 → 集成到 reward）
- **配置驱动**：所有组件通过 `launch/*.yaml` → `factory.py` 从配置构建
- 当前 UniDock 链路已接入 8GJL 靶点，AutoDock-GPU 保留为备选后端

## 4. 关键模块职责（做任务时优先看这些）

### 4.1 训练入口
- `ddpo/main_diffsbdd_ddp.py`
  - **当前唯一主入口**，PyTorch 原生 DDP（`torchrun` 启动）
  - 负责：读配置、建模、建 reward/filter/rollout、执行 DDP 训练循环、checkpoint 与日志
  - 启动方式：`bash launch/run_6gpu_dock.sh` 等

- `ddpo/main_diffsbdd_single_gpu.py`
  - 单 GPU 入口，legacy，不再作为主要训练入口
  - 保留用于快速调试

- `ddpo/main_diffsbdd.py`
  - 旧 Ray 入口，legacy，保留用于历史对照

### 4.2 模型适配
- `ddpo/integration/diffsbdd_model.py`
  - 把 DiffSBDD 模型包装成 RL 可调用接口
  - 处理 pocket 读取、采样接口、mask/格式桥接
- `ddpo/integration/mask_utils.py`
  - `batch_mask <-> node_mask` 双向转换

### 4.3 奖励系统（核心重构区，新增 2026-05）

| 文件 | 职责 |
|------|------|
| `ddpo/rewards/factory.py` | `build_rewarder()` 从 YAML 构建完整 rewarder |
| `ddpo/rewards/composite.py` | `CompositeReward` 加权组合 + `ComponentNormalizer` 集成 |
| `ddpo/rewards/component_normalizer.py` | 每分量 EMA z-score 归一化 |
| `ddpo/rewards/normalization.py` | `RewardNormalizer` 全局优势 z-score |
| `ddpo/rewards/chembl_classifier_reward.py` | **ChEMBL 二分类器奖励**（2220D MLP，当前核心组件） |
| `ddpo/rewards/chembl_prior_reward.py` | ChEMBL 指纹相似度（ECFP4/FCFP4） |
| `ddpo/rewards/molskill_reward.py` | MolSkill 人类偏好模型 |
| `ddpo/rewards/ligand_efficiency_reward.py` | 配体效率（LE = dock_score / heavy_atoms） |
| `ddpo/rewards/diversity_reward.py` | 批级多样性控制（ECFP4/FCFP4 惩罚） |
| `ddpo/rewards/logp_distribution_reward.py` | logP 分布对齐 ChEMBL 基线 |
| `ddpo/rewards/qed_reward.py` | QED 类药性 |
| `ddpo/rewards/sa_reward.py` | SA 合成可及性 |
| `ddpo/rewards/connectivity_reward.py` | 连接性检查 |
| `ddpo/rewards/docking.py` + `docking_factory.py` | UniDock 对接奖励 |
| `ddpo/rewards/stability.py` | `StabilityAwareReward` 包装器（注入 stability 字段） |

### 4.4 ChEMBL 分类器独立管线（`chembl_classifier/`）

独立于 RL 训练环的完整管线：
- **数据构建**：`data/extract_negatives.py`（属性规则提取异常分子）→ `data/build_dataset.py`（正负样本 + MolSkill featurizer → `dataset.pt`）
- **模型**：`model.py`（3 层 MLP：2220 → 512 → 128 → 1），输入 2048 Morgan FP + 172 RDKit 2D 描述子
- **训练**：`train.py`（BinaryCrossEntropy，batch=256，epochs=100）
- **评估**：`evaluate.py`（AUROC / 阈值分析）
- **集成**：训练好的 `.pt` 权重被 `ChemblClassifierReward` 加载，参与 RL 训练

### 4.5 分子描述子监控系统（2026-05-21 上线）

- `ddpo/utils/molecular_descriptors.py`：纯函数，不依赖训练基础设施
- 每 epoch 计算 22 个指标：LogP/TPSA/HBA/HBD/碳比例/杂原子/芳环/比例警报/MMD/指纹相似度
- 由 `ddpo/runtime/train_helpers.py` 上的 `compute_epoch_molecular_descriptors()` 触发
- 结果通过 `extra_metrics` 写入 `training_summary.csv`

### 4.6 训练执行模块
- `ddpo/runtime/rollout.py`：rollout 实现
- `ddpo/runtime/train_helpers.py`：训练循环编排 + 描述子计算
- `ddpo/runtime/recording/*`：记录输出（metrics_writer / molecule_writer / run_recorder）
- `ddpo/runtime/actor.py`：当前 policy update（从 RLPF actor 本地化）

### 4.7 记录与统计
- `ddpo/runtime/recording/molecule_writer.py`：分子级 CSV 记录 + epoch SDF 导出
- `ddpo/runtime/recording/metrics_writer.py`：`training_summary.csv`（含描述子 22 列）
- `ddpo/utils/diffsbdd_filter.py`：有效性过滤、SMILES 去重与可选新颖性惩罚

## 5. 配置与数据要点

### 5.1 主要配置文件（`launch/` 目录）

| 文件 | 用途 | 权重分配 |
|------|------|----------|
| `6gpu_dock.yaml` | 对接 + ChEMBL prior + logP | docking:0.4, chembl_prior:0.4, logp_distribution:0.2 |
| `6gpu_chembl_only.yaml` | ChEMBL 指纹 + logP + classifier | ECFP4:0.3, FCFP4:0.3, logP:0.2, classifier:0.2 |
| `7gpu_classifier_only.yaml` | 纯 classifier reward | chembl_classifier:1.0 |
| `7gpu_dock_classifier_v0_1.yaml` | 对接 + classifier | docking + chembl_classifier |
| `8gpu_dock.yaml` | 对接 + ChEMBL prior + logP | docking:0.4, chembl_prior:0.4, logp_distribution:0.2 |
| `8gpu_chembl_only.yaml` | ChEMBL 指纹 + logP | ECFP4:0.4, FCFP4:0.4, logP:0.2 |
| `molskill_test.yaml` | 纯 MolSkill 测试 | molskill:1.0 |
| `smoke.yaml` | 冒烟测试 | qed:1.0（1 GPU / 1 epoch / batch=4） |
| `smoke_docking_classifier_v0_1.yaml` | 冒烟测试（docking+classifier） | docking + chembl_classifier |
| `run.yaml` | 通用配置（配合 `run.sh`，默认 7GPU classifier） | chembl_classifier:1.0 |

关注字段：
- `reward.weights` — 组件启用与权重
- `reward.per_component_normalization` — 每分量 EMA z-score（enabled: true/false）
- `reward.normalization` — 全局 z-score + clamp
- `reward.<component>.*` — 各组件专属参数
- `model.checkpoint` — DiffSBDD 底座 checkpoint
- `pocket.pdb_path` — 蛋白口袋 PDB
- `train.epochs` / `train.batch_size_per_gpu`

### 5.2 关键数据路径
- UniDock 受体：`data/8gjl.pdbqt`
- AutoDock-GPU 备选：`data/8GJJ-C-Cip_charged.pdbqt`
- ChEMBL 指纹缓存：`data/chembl/chembl_36_ecfp4_fingerprints.pkl.gz` / `chembl_36_fcfp4_fingerprints.pkl.gz`
- ChEMBL 属性表：`data/chembl/chembl_36_properties.csv.gz`
- ChEMBL 分类器权重：`chembl_classifier/models/chembl_classifier.pt`

## 6. 启动命令

### 训练（多 GPU DDP）
```bash
bash launch/run_6gpu_chembl_only.sh      # 6 GPU: ECFP4+FCFP4+logP+classifier
bash launch/run_6gpu_dock.sh             # 6 GPU: docking+ChEMBL prior
bash launch/run_8gpu_chembl_only.sh      # 8 GPU: ChEMBL 指纹 + logP
bash launch/run_8gpu_dock.sh             # 8 GPU: docking+ChEMBL prior
bash launch/run.sh                       # 通用启动（CONFIG_PATH 指定配置，默认 run.yaml）
```

### 冒烟测试（每次改代码后必须运行）
```bash
bash launch/smoke.sh
```
自动执行：1 GPU / 1 epoch / batch=4 → 验证 DDP 全链路不崩溃 → 自动清理 GPU 显存和端口。

### ChEMBL 分类器训练/评估
```bash
cd chembl_classifier
python data/extract_negatives.py   # 提取负样本
python data/build_dataset.py       # 构建 dataset.pt
python train.py                    # 训练 MLP
python evaluate.py                 # 评估 AUROC
```

### 单 GPU 调试
```bash
python ddpo/main_diffsbdd_single_gpu.py --config_path launch/smoke.yaml
```

## 7. 日常任务建议

1. **先读本文件 + `docs/workflow_commands.md`**
2. 训练相关优先从：
   - `ddpo/main_diffsbdd_ddp.py`（主入口）
   - `ddpo/runtime/train_helpers.py`（训练循环编排）
   - `ddpo/runtime/rollout.py`（rollout）
   - `ddpo/integration/diffsbdd_model.py`（模型适配）
   - `ddpo/rewards/factory.py`（奖励构建）
   - `ddpo/rewards/chembl_classifier_reward.py`（分类器奖励）
3. 改奖励/扩散/mask 代码时，必须先确认：
   - 奖励语义不变（所有子类 `calculate_rewards` 签名一致）
   - 命名一致性链条完整（YAML → factory → reward → schemas → writer，参考规则文档）
   - timestep 语义不反转，mask shape 与 batch 语义正确
4. 输出文件统一进 `OUT/...`，分析文档统一进 `analysis/`
5. **改代码后必须跑冒烟测试**：`bash launch/smoke.sh`
