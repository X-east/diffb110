## 4. 关键模块职责

### 4.1 训练入口

| 入口 | 用途 | 说明 |
|------|------|------|
| `ddpo/main_diffsbdd_ddp.py` | 8卡生产 | torchrun + DDP，当前主生产线 |
| `ddpo/main_diffsbdd_single_gpu.py` | 单卡调试 | 本地调试和检查 |
| `ddpo/main_diffsbdd.py` | legacy | 含 Ray 逻辑，仅供历史兼容 |

### 4.2 模型适配

- `ddpo/integration/diffsbdd_model.py` — DiffSBDDModel 包装器，处理 pocket 读取、采样接口、mask 桥接
- `ddpo/integration/mask_utils.py` — batch_mask ↔ node_mask 双向转换

### 4.3 奖励系统（4层解耦）

| 层 | 文件 | 职责 |
|----|------|------|
| 语义层 | `docking.py` | 奖励计算主逻辑、批量编排 |
| 准备层 | `docking_preparation.py` | SDF 输入准备、加氢、Gasteiger 电荷 |
| 配置层 | `docking_config.py` | 常量、默认值、FAILURE 常量 |
| 后端层 | `docking_backends/` | UniDock / AutoDock-GPU / Smina 实现 |
| 注册层 | `docking_registry.py` | 后端名 → 类的注册与选择 |

- `composite.py` — 奖励加权组合
- `normalization.py` — z-score 归一化
- `qed_reward.py` / `sa_reward.py` — QED / SA

### 4.4 分子语义管线

- `molecule_semantics.py` — 统一分子构建 + 过滤 + 加氢 + 电荷
  - `build_canonical_rdmol_from_sample()` — 从扩散样本构建 rdmol
  - `prepare_mol_for_docking()` — 深拷贝 + AddHs + Gasteiger
  - `write_rdmol_to_sdf()` / `write_rdmol_to_pdbqt()`

### 4.5 KL 散度约束

- `ddpo/kl/gaussian_kl.py` — 纯张量 KL 计算
- 接入点：`edm_actor.py` → `calculate_loss()`
- `kl_coef` 在 YAML 配置中设置（当前默认 0.0）
- ref_model 通过 `copy.deepcopy` 创建，`torch.no_grad()` 前向

### 4.6 运行时

- `runtime/build.py` — 工厂函数，从 YAML 构建全部组件
- `runtime/rollout.py` — 轨迹采样
- `runtime/recording/` — 训练记录

### 4.7 策略更新

- `RLPF-verl_diffusion/verl_diffusion/worker/actor/edm_actor.py`
  - EDMActor.calculate_loss() → PPO clip + kl_coef × KL
  - ref_model 前向在 torch.no_grad() 中

## 6. Molecule 语义统一（必读）

详见 `docs/project_context.md`，核心决议：

1. **OpenBabel** 负责从扩散几何重建结构 / 感知建键
2. **RDKit Mol** 是唯一下游化学对象
3. OpenBabel 判定不合理 → 最大惩罚，跳过所有下游
4. `rdkit_valid` 作为 docking 前置门
5. QED / SA 只从同一 rdmol 计算
6. docking 输入只从同一 rdmol 导出
7. SMILES 只用于日志、去重与 novelty
8. 最终总分是显式分项加权组合

## 7. 日常任务建议

1. 先读本文件 + `docs/workflow_commands.md`
2. 训练相关优先看：
   - `ddpo/main_diffsbdd_ddp.py`
   - `ddpo/runtime/rollout.py`

   - `ddpo/rewards/*`
3. 改奖励/扩散/mask 代码时，必须先确认：
   - 奖励语义不变
   - timestep 语义不反转
   - mask shape 与 batch 语义正确
4. 输出统一进 `OUT/...`，分析文档统一进 `something/`
5. 多卡启动用 `torchrun + ddpo/main_diffsbdd_ddp.py`
