## 一、任务与共同口径

- **任务**：RE-CmeB / 8GJL-C1101 口袋条件化 3D 分子生成；DiffSBDD 为离线数据承载模型。
- **参照系**：ChEMBL 小分子参照集 **1,790,085** 条（`data/chembl_smallmol_reference/`，10 元素白名单、去重、无尺寸窗口）。
- **评价四件套**（任何生成结论都要给全）：
  1. 固定尝试数（不补无效分子）、`seed = gpu_id`；
  2. 宽松 sanitize 率；
  3. R1–R5 结构合规（目标线：ChEMBL HA10–30 = **90.60%**）；
  4. 对接（LF + 无 H，clean & HA10–30 口径）与**形态护栏**（0 环率 / QED / 单片段率）。
- **环境**：主环境 `dif`；触碰 DiffGui 模型用 `diffgui`（隔离）。GPU 优先，沙箱内 `cuda.is_available()==False` 不能当证据。

## 三、各管线一句话结论（速查）

| 管线 | 结论 |
|---|---|
| ESRPO | 能拟合 endpoint 去噪偏好；structure-matched x-only 在低/中 timestep 有可测信号；但 pair accuracy 与生成质量多次脱钩（最强拟合部分来自 `v` 元素组成 shortcut）。固化为主线依据是 9/2 的 1000-attempt 生成对比 |
| **ESRPO-ChEMBL 版** | ChEMBL 作 winner 的跨源偏好对：**HA 匹配是必须的**（否则尺寸成为可套利信号）；size 匹配后简单化 hacking 被消除（0 环 1–4%、QED 0.50–0.58），对接 −9.50（优于 Original 0.53）；**R1–R5 仍 ~41.7%（目标 90.6%）**，loser 定义漏洞待修 |
| 在线 DDPO | 最早成型的 RL 路线；作“为什么转向离线”的证据 |
| Global DPO（硬标签） | 可拟合硬标签（acc 0.58–0.62）但与生成质量严重脱钩——最明确反例：`global_dpo_t1000_epoch5` 碳比例 0.752 → 0.067、QED 0.613 → 0.075 |
| 离线 IQL | 横评 → 100k 轨迹 → 离线 MDP；**尚无证据 IQL 优于 Original** |
| DiffGui RL | 20 个主要训练（6 个 `next6` 核心矩阵）；横评基线与历史结果，不参与本路线训练 |
| ChEMBL 分类器 | 不能单独承担类药约束，需与 D-MPNN / ring facts / docking / 规则审计配合 |
| 跨模型横评 | 五模型固定尝试数；DiffGui 生成指标高，但结构病理口径下 DiffSBDD 保留线更可控 |
